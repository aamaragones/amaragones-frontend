# Contributing

Thank you for contributing. Please follow these guidelines:

- Use Markdown files for docs and specs.
- Keep files small and focused (one topic per file).
- Use the templates under each folder when creating new artifacts.
- Open PRs against `main` and reference related product or SDD files.
- For diagram syntax, prefer Mermaid embedded in Markdown.

Refer to the individual folder READMEs for more details.
